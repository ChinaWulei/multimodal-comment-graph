# 预测连接诊断实验

本目录不修改原 MFCL、生成器、前轮实验及其检查点，也不使用测试集。

## 检查一：评论展示位置

复用上一轮固定的8条训练新闻，均未参与前轮质量标注。保持实际图片、标题、真实评论、节点编号和真实父节点不变，
仅将输入列表分别按原顺序、逆序和固定随机顺序展示。允许父节点列表仍按编号排序。
使用相同已微调 Qwen、4-bit 本地推理、贪心解码，每种条件生成一次 JSON，共24次。
不重试掩盖失败，不使用新闻标签，不更新生成器。不把生成节点再次放入上下文。

保存原始输出、实际图片路径、输入节点、输入长度、提示哈希、模型和输入文件哈希，逐条原子写入，支持继续。
只度量顺序敏感性。生成内容也可能随顺序改变，父节点改变不等于父节点错误；
反序列表不属于原先父节点在前的训练格式，8条也不足以推广总体结论。

## 检查二：固定内容的连接对照

直接复用前轮 A（真实评论）、D（生成评论全挂根节点）、E（模型预测父节点）三个种子的结果。
新增 H：在新闻内部交换生成评论的父节点，保持每个节点度数、边总数、真实边和全部文本图片不变。
本轮不增加额外根节点边。只有生成评论连接改变，不重新生成分类用评论。
若同一新闻所有生成评论都指向相同父节点，则保持度数的打乱无法改变该新闻，按原样保留并统计。

训练292条，主要验证44条，完整77条只作冻结检查点辅助验证；三种种子42/13/24，最多20 epoch、早停5、
batch8、学习率1e-4、真实评论最多16条、生成评论最多5条。复用 typed R-GCN、mean pooling、concat。
E 对 A/D/H 均需平均 Macro-F1 提升至少1个百分点且至少2/3种子提升；未达标不进入测试。
已有验证集已经探索，不是新的盲测。每条预测、每类指标、混淆矩阵和训练曲线均保留。
汇总重算 Macro-F1 并核验来源、检查点哈希、新闻 ID 及标签；配对新闻 bootstrap 不涵盖模型选择的不确定性。

## 本轮实际结果（2026-10-10）

已完成24次实际图文生成检查，以及H组3次训练、3次完整77条辅助验证。
5项单元测试、实际8条新闻图的前向/反向传播、来源哈希检查和逐新闻指标重算均通过。
完整生成结果再次续跑时文件哈希不变，没有重复生成。未训练Qwen，也未运行测试集。

主要验证集44条，以下为三个训练种子的均值±样本标准差；A/D/E复用冻结结果，H为本轮新训练。

| 方法 | Accuracy | Macro-F1 |
|---|---:|---:|
| A 仅真实评论 | 81.82% ± 4.55 | 81.74% ± 4.18 |
| D 同内容生成评论，挂新闻根节点 | 85.61% ± 1.31 | 85.39% ± 1.13 |
| E 同内容生成评论，预测父节点 | 85.61% ± 3.47 | 84.94% ± 3.69 |
| H 同内容生成评论，打乱父节点且不加边 | 84.09% ± 0.00 | 83.47% ± 0.20 |

标准差单位为百分点。H三个种子恰好均分类正确37/44条，但每类错误分布和逐新闻预测不同，不是重复运行同一结果。
E比H平均高1.47个百分点，2/3种子为正；配对新闻bootstrap 95%区间为[-3.98,+6.85]个百分点，仍跨0。
E比D低0.45个百分点，整体门槛未通过。仅可视为预测对应关系可能有价值的初步线索，不能宣称优于根节点连接。
这只是一个固定的连接打乱方案和三个训练种子，不能代表所有随机拓扑。

位置检查：原顺序7/8条输出有效，其中6条选最后展示节点；逆序8/8有效，仅1条选最后展示节点，但6条选最大编号；
随机顺序8/8有效，8条均选最后展示节点。在原顺序输出有效的7对新闻中，随机顺序使7对父节点均改变，逆序使2对改变。
所有有效配对的评论正文也改变，因此不能把父节点变化直接解释为错误。原顺序另1条重复输出直到160 token上限，
JSON不完整，已记录为失败，没有重试填补。24次生成约82秒，峰值分配显存3.50GiB；H分类训练峰值约1.41GiB。

保持度数的打乱实际改变训练集226/292条新闻的598/1458条生成连接、验证集56/77条新闻的156/385条连接；
其余无法改变的新闻照常保留。后续可单独验证固定评论内容下的父节点选择，或小规模测试打乱展示顺序的SFT数据增强；
这些改动尚未实施，也不能提前声称能提升分类指标。
